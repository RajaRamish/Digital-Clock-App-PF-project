# 🕒 Digital Clock Project

A **C++ Graphics-Based Digital Clock** that displays real-time time information with visually appealing graphical effects and animations. The project explores computer graphics concepts by combining real-time clock functionality with dynamic backgrounds, particle effects, fireworks, and animated visuals.

This project demonstrates creativity while strengthening programming skills in graphics programming, animation, and modular software development.

---

## 📌 Features

* Real-time digital clock display
* Dynamic animated backgrounds
* Fireworks animation
* Falling stars effect
* Particle system implementation
* Time zone support
* Smooth graphical rendering
* Modular project architecture
